# Graphing Calculator
C# Graphing Calculator for the OOP unit custom project.<br>
An extensive design overview can be found under the documentation folder.<br>

### Instalation
Using SplashKit library V1.3.0 https://splashkit.io/<br>
Using dotnet V10.0.201<br>

### Controls
- Use the text box in the lower right of the window to enter new graphs and coordinates. Press enter to submit
- 	Type an expression (do not include y) E.g. "sin(2x)" or "2abs(x^2-30)"
- 	Or type a coordinate separated by a comma E.g. "5,2" or "(5,2)"
- 	Entries can also be entered as an argument to dotnet run
- [W][A][S][D] Move the camera around
- [E][Q] Zoom in and out
- Use "delete:" before an expression or coordinate to delete all those with that identity
